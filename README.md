# Axon Protocol

✨ **Axon —— 区块链的中枢神经，重新定义Web3交互** ✨

🥳 把复杂的区块链，变成人人都会用的简单工具。打破链、Gas、授权的壁垒，让用户无需懂技术，只需专注 “用”，不用操心 “怎么实现”。

🚀 继承 KubePivot 式的降维逻辑，以 Axon 为中枢，联动 Web3-blitz 底层引擎，把所有繁琐操作藏在后台，只留给用户最直观的体验。


## 🚀 项目定位

Axon 不是简单的钱包或协议，而是 💎 **Web3 全场景极简交互中枢** 💎：

- ✅ 对用户：零门槛、一键操作，无需懂链、无需懂Gas、无需懂授权，像微信支付一样顺滑

- ✅ 对开发者：提供统一抽象接口，屏蔽多链差异，快速对接所有链上资源

- ✅ 底层联动：基于 Web3-blitz 实现链交互、签名、跨链、兑换等核心能力，专注上层极简体验落地


## ✨ 核心特性

1. 🔗 **无感多链路由**：自动识别用户资产所在链，智能选择最优路径（速度最快、手续费最低），无需手动切换链网络

2. ⛽ **Gas 自动代付**：用户无需持有 ETH、BNB 等原生 Gas 币，协议后台统一垫费，仅扣稳定币（USDT/USDC）

3. 💸 **一键万能操作**：充值（万能收款码）、转账（手机号/用户名/二维码）、兑换（1秒到账）、DApp交互（自动授权），全流程极简

4. 🌐 **全栈生态适配**：支持 Axon Pay（C端App）、Axon Wallet（钱包模块），无缝对接 Web3-blitz 底层引擎，可扩展DeFi、NFT等场景

5. 🔒 **安全可控**：基于成熟的签名机制和链交互逻辑，兼顾用户体验与资产安全，无隐藏手续费、无暗箱操作


## 🏗️ 架构设计

🧩 三层架构，完全解耦，可扩展、易维护，复刻“微信 + 微信支付引擎”的成功逻辑：

1. 🖥️ **上层：Axon 生态产品**（Axon Pay / Axon Wallet）—— 极简C端界面，负责用户交互

2. ⚙️ **中层：Axon Protocol** —— 核心抽象层，负责链路由、Gas代付、统一接口调度

3. 🔧 **底层：web3\-blitz** —— 链交互引擎，负责签名、跨链、合约调用等“脏活累活”


## 📡 统一接口（开发者友好）

📞 屏蔽所有链差异，仅暴露4个核心接口，快速对接：

```http
# 查询余额
GET /api/v1/balance

# 充值（获取万能收款地址）
GET /api/v1/deposit

# 转账（无需选链，自动匹配最优路径）
POST /api/v1/transfer

# 稳定币兑换（USDT ↔ USDC 等，1:1无感兑换）
POST /api/v1/swap
```
