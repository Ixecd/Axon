# ADR 002 — Account Abstraction (ERC-4337)

> 日期：2026-05-11 | 状态：draft | 作者：qc + DeepSeek

---

## 决策

采用 **ERC-4337 v0.7 EntryPoint + custom Paymaster**。智能账户由工厂合约 (AccountFactory) 创建，支持 Session Key + 社交恢复 + 批量交易。

## 为什么不是 v0.6

| 方面 | v0.6 | v0.7 |
|------|------|------|
| EntryPoint | `0x5FF137...` (hardcoded) | 升级版，更优 Gas 优化 |
| Paymaster | postOp 限定 | 更灵活 refund 模式 |
| Auditor 覆盖 | OpenZeppelin 已审计 | 较新但社区迁移中 |

v0.7 选型原因：**Gas 优化**（postOp gas refund 更精确），且 v0.6 → v0.7 迁移路径清晰。Axon 从零开始，无历史负债，直接 v0.7。

## 合约架构

```
AccountFactory.sol
  └─ createAccount(owner, salt)
       └─ SimpleAccount.sol (ERC-4337 compliant)
            ├─ validateUserOp()    签名验证 (ECDSA via MPC key)
            ├─ execute()           批量 tx
            └─ executeBatch()      批量操作

Paymaster.sol  (custom)
  ├─ validatePaymasterUserOp()   Gas 代付判定
  ├─ postOp()                    Refund 结算
  └─ deposit()                   Axon Gas 金库充值

EntryPoint.sol  (引用 EIP-4337 标准)
  └─ handleOps() → 统一入口
```

## 关键设计

### Session Key（无感签名）

用户首次授权时 MPC 签一次 `enableSessionKey`。之后小额转账/支付走 Session Key，无需 MPC 协同。Session Key 有过期时间 + 金额上限。

### 社交恢复

账户 owner = MPC 公钥。备选恢复方式：
1. 邮箱 OTP → 触发 recovery 流程，Axon 协签 recovery tx
2. 社交守护人（Guardian）→ 不依赖 Axon 服务端

### Paymaster Gas 代付

用户交易发送 `PaymasterAndData`。Paymaster.validatePaymasterUserOp() 检查：
- Gas 金库余额 > tx gas × maxFeePerGas × 安全系数(1.5)
- 用户非黑名单
- 限额内（单笔 + 日累计）

## 与 axon-design.md v1 的差异

v1 设计文档 (Go 版) 标注 `EntryPoint.sol` 引用标准。v2 Rust 版自行部署 custom Paymaster + AccountFactory，不依赖第三方 bundler。
