# ADR 004 — Gas 金库与波动风险分担

> 日期：2026-05-11 | 状态：draft | 作者：qc + DeepSeek

---

## 决策

独立 Gas 金库（多签托管），**不从用户资金池挪用**。Gas 预估 × 安全系数(1.5)，极端拥堵平台兜底。

## 金库架构

```
Gas 金库 (多签钱包, 3/5 signers)
├── Ethereum: ETH  30% 预留
├── Polygon:  MATIC 20% 预留
├── BSC:      BNB   20% 预留
├── Arbitrum: ETH   15% 预留
└── Optimism: ETH   15% 预留

监控规则:
  balance < 预警线 (2× daily_avg) → 链下充值警报
  balance < 止损线 (0.5× daily_avg) → 暂停该链垫付, 用户走原生 Gas
```

## Gas 波动风险分担

```
预估 Gas = 实时链上 maxFeePerGas × gasLimit × 安全系数(1.5)

实际扣费: 按 tx receipt 的 actualGasUsed × effectiveGasPrice
差值 = 预估 - 实际

差值 <= 安全系数边界:  用户承担 (正常波动)
差值 > 安全系数边界:   Axon 承担超额部分
超过单笔 Gas 上限:     拒绝垫付, 通知用户手动处理
```

## 稳定币 → Native Token 对冲

```
主方案: 后台预储备 + Oracle 记账对冲

1. Axon 后台预先在各链备好 ETH/BNB/MATIC
2. 用户支付 USDC/USDT
3. 系统内部按实时 Oracle 汇率记账
4. 平台定期集中处理稳定币 ↔ Native 仓位再平衡

优点: 避免 DEX 滑点 / MEV / 兑换延迟

备用方案: 链上兑换 (仅在仓位再平衡时)
  Ethereum: Uniswap V3
  BSC:      PancakeSwap
  强制: min_slippage=0.5% + single_tx_cap + fail_rollback
```

## Paymaster 配额模型

```
每用户:
  - single_tx_gas_cap:    0.05 ETH 等值
  - daily_cumulative_cap: 0.5 ETH 等值
  - monthly_cumulative_cap: 3 ETH 等值

超限: 拒绝垫付, 提示用户自付 Gas 或等次日
```

与 KubePivot WorkerPool token bucket (10 tokens/sec) 同构：
- token = Gas 配额
- bucket refill = 每日 / 每月重置
- 突发保护 = single_tx_cap
